# Melumia
Dynamic lyric display with screen ambient light. Free and open source.

**Made by:** [Onix](https://github.com/OnixByte)
>⚠️ This project is currently in development

## Planned features
-> ❌ Synchronized lyrics with smooth scrolling
-> ❌ Luminous halo with slow color changing
-> ❌ Color picked from the album jacket
-> ❌ Detection of the current playing track
-> ❌ Desktop application (overlay)
